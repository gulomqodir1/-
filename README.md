# 🤖 CYBER-STRIKE: TRANSFORMERS 3D

Увлекательная 3D браузерная игра, объединяющая тактический шутер в стиле **Counter-Strike** и динамичную боевую трансформацию **Трансформеров** (Autobot Commando).

Разработано на чистом **JavaScript + Three.js** с процедурным звуковым движком на **Web Audio API** (работает автономно без сторонних текстур и аудио-файлов!).

---

## 🎮 Как запустить игру (Qanday ishga tushirish kerak)

1. Просто откройте файл `index.html` в любом современном браузере (Google Chrome, Microsoft Edge, Firefox, Opera, Brave).
2. Нажмите **"НАЧАТЬ БОЙ (DEPLOY)"** или кликните по экрану, чтобы заблокировать мышь и начать бой.

## 🕹️ Управление (Boshqaruv tugmalari)

| Клавиша | Действие (Действие в игре) |
| :--- | :--- |
| **W, A, S, D** | Перемещение пешком / Управление машиной при вождении |
| **Мышь (Mouse)** | Прицеливание / Обзор на 360° |
| **ЛКМ (Левая кнопка)** | Стрельба из винтовки / AWP / Удар клинком / Огонь из пушек машины |
| **ПКМ (Правая кнопка)** | Оптический прицел снайпера AWP (Scope Zoom) |
| **T** или **E** | ⚡ **ТРАНСФОРМАЦИЯ** (Переключение между Роботом и Машиной!) |
| **Shift** | Спринт (в режиме робота) / **НИТРО ТУРБО** (в режиме машины) |
| **Пробел (Space)** | Прыжок робота |
| **R** | Перезарядка обоймы оружия |
| **1, 2, 3** | Выбор оружия: [1] Винтовка, [2] AWP Снайперка, [3] Энергон Клинок |
| **Tab** | Таблица счета (Scoreboard) |
| **Esc** | Выход из режима мыши / Пауза |

## 🚀 Ключевые особенности игры

1. **Режим Робота (Counter-Strike FPS)**:
   - Шутер от первого лица с 3D-оружием в руках, отдачей, покачиванием при ходьбе и дульной вспышкой.
   - Динамический прицел CS, расширяющийся при стрельбе.
   - Звук хедшота со звоном шлема и множителем урона.
   - Тактический радар (миникарта) с точками десептиконов и плентами **A** и **B**.
   - Таблица счета (Hold `Tab`), Киллфид (уведомления об убийствах) и счетчик раунда.

2. **Режим Боевой Машины (Трансформер)**:
   - Нажатие `T` запускает звуковую и визуальную трансформацию: робот превращается в футуристичный Cyber-Cruiser, а камера переходит в вид от 3-го лица.
   - Высокая скорость, физика дрифта, поворот колес.
   - **ТАРАН (Ram Kill)**: Сбивайте десептиконов на высокой скорости!
   - **НИТРО**: Зажмите `Shift` для ускорения с реактивным пламенем из выхлопных труб.
   - Двойные капотные лазерные пушки (стрельба на ЛКМ).

3. **Интерактивная карта и Враги**:
   - Ящики CS, пандусы, тактические укрытия, точки минирования A и B.
   - Красные энергонные бочки — стреляйте по ним, чтобы устроить мощный взрыв и уничтожить группу врагов.
   - Искусственный интеллект врагов-десептиконов: патрулирование, преследование, ведение прицельного лазерного огня.
   - Разные классы врагов: разведчики (Scout), штурмовики (Trooper), тяжелые титаны (Titan).
